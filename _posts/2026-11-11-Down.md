Down is an easy-rated Linux machine that involves exploiting an arbitrary file read by bypassing a protocol-based filter to discover the source code of the running PHP web app, eventually, a remote code execution to gain an initial foothold. The attacker finds a readable pswm encrypted file in the user's home directory. The pwsm uses Python's cryptocode module and a master password to encrypt and decrypt the data. The attacker is supposed to write a small script to decrypt the blob and compromise the user. The compromised user is a member of the sudo group, allowing the user to escalate and obtain root access.

We can take alot from this. We see first that it does indeed use curl. We also see a expertmode we havent seen yet. It uses nc instead of curl. If we check the code we can see the main problem. 

The application has a TCP check mode enabled bia 'expertmode=tcp', which takes a user supplied ip and port and then passes them to netcat.
```terminal
$ec = escapeshellcmd("/usr/bin/nc -vz $ip $port");
exec($ec . " 2>&1", $output, $rc);
```
The dev tried to validate the inputs and uses 'escapeshellcmd()' to try to sanitize the command. But this is wrong and has a massive flaw.
The ip is properly validated with 'FILTER_VALIDATE_IP' so you cant inject through the field. However the port validation is broken.
```terminal
$port = trim($_POST['port']);
$port_int = intval($port);
$valid_port = filter_var($port_int, FILTER_VALIDATE_INT);
```
The 'interval()' will parse the leading integer from any string. So a value like 80 ; id becomes 80, which passes 'FILTER_VALIDATE_INT'. But the worst is the original unsanitized '$port' string is what gets interpolated into the command, not '$port_int'. The validated value is never used.

```terminal
┌──(songbird㉿kali)-[~/Desktop/down]
└─$ cat crack_pswm.py 
#!/usr/bin/env -S uv run --script
# /// script
# requires-python = ">=3.8"
# dependencies = [
#   "cryptocode",
# ]
# ///
import cryptocode
import sys

def crack_pswm(vault_file, wordlist):
    with open(vault_file, 'r') as f:
        encrypted = f.read().strip()

    print(f"[*] Loaded encrypted vault: {encrypted[:40]}...")
    print(f"[*] Starting bruteforce with wordlist: {wordlist}\n")

    with open(wordlist, 'r', encoding='latin-1') as f:
        for i, line in enumerate(f):
            password = line.strip()
            result = cryptocode.decrypt(encrypted, password)

            if result is not False:
                print(f"[+] Master password found: {password}")
                print(f"[+] Decrypted vault contents:\n{result}")
                return password

            if i % 100000 == 0 and i != 0:
                print(f"[-] Tried {i} passwords... (last: {password})")

    print("[-] Password not found in wordlist.")
    return None

if __name__ == "__main__":
    if len(sys.argv) != 3:
        print(f"Usage: {sys.argv[0]} <vault_file> <wordlist>")
        print(f"Example: {sys.argv[0]} pswm /usr/share/wordlists/rockyou.txt")
        sys.exit(1)

    crack_pswm(sys.argv[1], sys.argv[2])
```
